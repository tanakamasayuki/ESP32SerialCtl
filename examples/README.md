# ESP32SerialCtl examples

> 日本語版: [README.ja.md](README.ja.md)

## Workflow and individual READMEs

Start with the [example workflow](../docs/GUIDE_EXAMPLES.md), then choose the relevant sketch.

A useful starting point is [SimpleTest](SimpleTest/README.md). Check its required hardware and choose another entry below if it does not match your setup.

| Example | Learn |
|---|---|
| [BasicCli](BasicCli/README.md) | Expose named GPIOs and an initialized test filesystem |
| [CommandDemo](CommandDemo/README.md) | Register application commands and argument descriptions |
| [ConfigDemo](ConfigDemo/README.md) | Read application settings and expose configuration commands |
| [SimpleTest](SimpleTest/README.md) | Run the minimal built-in serial command interface |
| [StorageTest](StorageTest/README.md) | Inspect mount results for several storage backends |
| [WiFiTest](WiFiTest/README.md) | Use serial commands to configure and inspect Wi-Fi |
