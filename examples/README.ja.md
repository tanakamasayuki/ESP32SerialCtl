## 実行ガイドと個別README

| [SimpleTest](SimpleTest/README.ja.md) | 最小構成で組み込みシリアルコマンドを動かす |
| [StorageTest](StorageTest/README.ja.md) | 複数のストレージのmount結果を調べる |
| [WiFiTest](WiFiTest/README.ja.md) | シリアル操作でWi-Fiを設定・確認する |
